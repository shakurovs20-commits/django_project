# Django Project (Социальная сеть)

Это учебный проект — прототип социальной сети, написанный на Python с использованием фреймворка Django. 

## 🚀 Функционал
* Регистрация, авторизация и смена пароля пользователей.
* Создание, редактирование и удаление постов (с возможностью прикреплять картинки).
* Комментирование постов.
* Разделение постов по группам (сообществам).
* Подписка на других авторов и лента избранных постов.
* Реализован REST API (через Django REST Framework) с токен-аутентификацией.
* Настроена админ-панель для управления контентом.

## 🛠 Стек технологий
* **Язык:** Python 3
* **Фреймворк:** Django, Django REST Framework
* **База данных:** PostgreSQL
* **Фронтенд:** HTML, CSS (Bootstrap)
* **Инфраструктура:** Docker, Docker Compose

## 📦 Как запустить проект (через Docker)

1. Убедитесь, что у вас установлен [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Склонируйте репозиторий или скачайте архив с проектом.
3. Откройте терминал в корневой папке проекта (где находится файл `docker-compose.yml`).
4. Выполните команду: docker compose up --build
5. После сборки контейнеров проект будет доступен по адресу: http://127.0.0.1:8000/
